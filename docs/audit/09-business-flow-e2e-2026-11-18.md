# Business flow end to end, real model: 2026-11-17/18

This report covers the full application, tested end to end on a laptop Compose stack (Windows 11, Docker 29.6.1). The code was `dev` plus #834 (Masters 0.3) and #847 (`compose-smoke` fixes). The LLM was **OpenRouter `openai/gpt-4o` through Bifrost**, with Langfuse tracing on and the spend capped (`LLM_PROJECT_BUDGET_USD` / `LLM_TENANT_BUDGET_USD`). Total model spend for the whole run was **$0.27**.

## The flow tested

The flow was Admin → Admin Masters → FDE:
1. The admin creates a project and invites a new FDE.
2. The admin assigns the project to that FDE and writes the project's masters.
3. The FDE sees only that project and its masters.
4. The FDE runs the pipeline.

A Playwright scenario drove it through the real web app, with real Keycloak logins and the invite email read from Mailpit.

## Findings not fixed here

- **F1:** an invited user must type a first and last name on first sign-in. Keycloak's `VERIFY_PROFILE` requires them, and the invite (`UserInvite`) takes only an email and roles. It works, but it's friction. Suggestion: optional `first_name` / `last_name` on the invite.
- **F2:** `secret-scan` on `dev` is red because of `origin/764-connections-secrets` (WIP fixtures shaped like a Stripe key and generic API keys in `5b8315c`), not `dev`. gitleaks scans `--all` and the CI checkout fetches every branch. `dev`'s own history scans clean (520 commits, 0 leaks). Reported on #764.
- **F3:** a dollar budget refusal reaches the FDE as `GENERATION_FAILED` (`pipeline.failed`, `error: BudgetExceeded`, next action retry), not as a `TOKEN_BUDGET_*` notification. Those notifications belong to the token caps. That's by design, but the UI could name the budget.
- **F4:** the LLM, OCR and Cognee integration tests need `LLM_PROVIDER=mock`, as their headers say. With a real key they fail. With mock: 50/50 pass.

## How to reproduce
- The scenario spec lives outside the repo (`client/e2e/stack/zz-business-flow.spec.ts`, local only). It uses the stack helpers in `client/e2e/stack/stack.ts`, and Mailpit on `:8025` for the invite link.
- Run it with: `E2E_STACK=1 E2E_BASE_URL=http://localhost:3000 pnpm --dir client exec playwright test --project=stack --workers=1`.
- Cap the spend with `LLM_PROJECT_BUDGET_USD`, and keep the RFQ to a few lines.
