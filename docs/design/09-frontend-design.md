# TD §9. Frontend design (Next.js + Refine)


## 9.1 Architecture

- Next.js App Router. Server components for layout/shell. **Client components** for AG Grid, TipTap, Monaco, Uppy and Xyflow (`"use client"`, dynamic import with `ssr: false`).
- Refine (`@refinedev/core` + `@refinedev/nextjs-router`) with a custom `dataProvider` (REST + problem+json) and `accessControlProvider` (roles from session).
- Auth.js with the Keycloak provider. The access token is held server-side and forwarded by a Next.js route handler proxy (`/api/proxy/*`) *(proposed)*, so tokens never reach browser storage.
- Generated TS types from `packages/contracts`. Forms use JSON-Schema-driven components (RJSF or equivalent *(proposed)*) for masters.
- Polling hook `useRun(runId)` refreshes every 3–5 s while a Temporal run is active.
- Common states on every screen: loading skeleton, empty state with next action, error panel (problem+json), forbidden, locked (423 → "frozen / approved — create a new version").
