# TD §2. Terminology and hierarchy


```text
Tenant (client organisation, isolated)
 └── Project            created by Admin (Admin portal); holds masters context; FDEs assigned
      ├── Documents (uploads, ≤20 per project, ≤15 MB each)        ← FDE uploads and drives the pipeline
      ├── Knowledge version (Cognee graph + OKF Bundle)
      ├── SOW (versions; FDE approves one version)
      └── Workflow      generated by SBAM from an approved SOW version (never created by the FDE);
           │            the unit that is finally certified + frozen
           └── Macro Skills  (= agents, id MSnn: major modules of the solution)
                └── Sub-Skills (= skills, id MSnn.m: smallest implementable features)
                     ├── ISATVON 1.4 definition (I, S, A, T, V incl. 5 loop bounds, O incl. state handoff, N)
                     ├── Skill Manifest (ISATVON 1.4 format + sbam_build_record) — contract for code generation
                     ├── Code attempts       (Jinja2 skeleton + LLM bodies → Action tool + Fixed Check tool)
                     ├── Gate results        (AST, Ruff, Black, MyPy, ClamAV, Bandit, imports, schema SQL)
                     ├── Test dataset + ≥3 loop scenarios (Promptfoo) run by the loop harness in CubeSandbox
                     └── Certification       (auto; manifest lifecycle = APPROVED)
           Workflow manifest = all certified Macro Skills + Sub-Skill manifests → certified → frozen → export
```

| Term                        | Meaning                                                                                                              |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **Admin**             | Keycloak role`sbam-admin`; uses the Admin portal: projects, masters, RBAC.                                         |
| **FDE** | Keycloak role `sbam-fde`; uses the FDE portal to drive the project pipeline: upload, review/approve SOW, review ISATVON, Generate, retry, export. **Never creates a Workflow.** |
| **Super-admin**       | Platform role that creates tenants (O-11).                                                                           |
| **Workflow** | SBAM business object generated by SBAM from an approved SOW version (never a Temporal workflow; never created by the FDE). |
| **Temporal workflow** | Durable execution in Temporal (`ProjectPipeline`, `SubSkillBuild`, …).                                         |
| **Certified**         | All gates passed (automatic).**Frozen** = certified and immutable.                                             |
| **N field**           | "Next / Notification": an in-app notification, then advance to the next step (C-18).                                 |
