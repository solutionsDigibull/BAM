# TD §3. End-to-end user flow


## 3.1 Admin portal

| #  | Actor / screen           | Action                                                                                                                                                                                                                                               | System does                                                                                                                                                     | User sees                                                     |
| -- | ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| A1 | Admin → Login (Admin)   | Signs in via Keycloak                                                                                                                                                                                                                                | Validates`sbam-admin` role + tenant                                                                                                                           | Admin dashboard                                               |
| A2 | Admin → Projects        | Creates project (name, client, description, context notes), assigns FDEs                                                                                                                                                                             | Creates project, audit entry                                                                                                                                    | Project detail                                                |
| A3 | Admin → Masters         | Maintains Organization, Rules, Agents and Skills rows (BAM 0.2 columns), views the frozen Filetype table, attaches master documents (routed to a master by Filetype default route), or imports/exports the consolidated masters workbook (`.xlsx`) | Validates the frozen structure and rows ([§7.3.1](07-database-design.md)), extracts stable IDs and status from the rows, versions entries; marks dependent knowledge "context outdated" | Master tables with version history; guideline help per master |
| A4 | Admin → Users & Roles   | Invites users, sets roles, assigns to projects                                                                                                                                                                                                       | Keycloak +`project_members`                                                                                                                                   | User list                                                     |
| A5 | Admin → Registry (read) | Views allowed runtime libraries                                                                                                                                                                                                                      | —                                                                                                                                                              | Runtime registry with image digest                            |

## 3.2 FDE portal

| #   | Actor / screen                  | Action                                                                                                                                                                                                                    | System does (automatic)                                                                                                                                                                                                                                                            | User sees / decision                                                                                  |
| --- | ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| F1  | FDE → Login (FDE)              | Signs in                                                                                                                                                                                                                  | Validates`sbam-fde` + tenant                                                                                                                                                                                                                                                     | My projects                                                                                           |
| F2 | FDE → Project overview | Opens the assigned project (created by the Admin) | Shows the project pipeline timeline; `ProjectPipeline` waits for documents | Project page with step timeline (no "create Workflow" action) |
| F3  | FDE → Upload                   | Drops files in Uppy, clicks**Start processing**                                                                                                                                                                     | tus upload → ClamAV → type check → parse → LLM OCR where needed                                                                                                                                                                                                                | Per-file status: Scanning → Parsing → Parsed / Rejected (reason)                                    |
| F4  | —                              | —                                                                                                                                                                                                                        | When all files are parsed or failed: Cognee build with uploads + master snapshot → OKF Bundle → notification                                                                                                                                                                     | "Knowledge ready". Knowledge Explorer becomes available (read-only)                                   |
| F5  | —                              | —                                                                                                                                                                                                                        | One-shot SOW generation from OKF Bundle → validation → SOW v1 → notification                                                                                                                                                                                                    | "SOW ready for review"                                                                                |
| F6  | FDE → SOW                      | Reviews; edits in TipTap; opens citations; saves (new version each save); exports if needed                                                                                                                               | Version + hash + diff                                                                                                                                                                                                                                                              | **Decision:** Approve, or keep editing or regenerate                                            |
| F7  | FDE → SOW                      | **Approve SOW**                                                                                                                                                                                                     | Locks version, records approval, signals pipeline → ISATVON breakdown (Macro → Sub-Skills) → notification                                                                                                                                                                       | "Breakdown ready"                                                                                     |
| F8  | FDE → ISATVON Workbench        | Reviews Macro Skills (MSnn) and Sub-Skills (MSnn.m) in AG Grid with ISATVON 1.4 columns (I, S, A, T, V bounds, O, N); edits fields; deletes unneeded Sub-Skills; regenerates a Macro/Sub-Skill with a hint; exports Excel | Revalidates every edit ([§10.4](10-isatvon-1-4-contract.md))                                                                                                                                                                                                                                                    | Valid/invalid badges.**Generate** enabled when all valid                                        |
| F9  | FDE → Workbench                | **Generate**                                                                                                                                                                                                        | Workflow schema.sql built; per Sub-Skill (parallel): Skill Manifest → library check → Jinja2 skeleton + LLM bodies (action + check tools) → AST vs manifest → Ruff/Black/MyPy/ClamAV/Bandit → loop scenarios (≥3) → loop harness in CubeSandbox + Promptfoo → auto-certify | Build & Test dashboard: live gates per Sub-Skill; badges in grid                                      |
| F10 | — (on failure)                 | —                                                                                                                                                                                                                        | Correction attempt 1 → re-run gates → attempt 2 → if still failing:`NEEDS_FDE_REVIEW` + notification                                                                                                                                                                          | **Decision:** FDE edits ISATVON / test cases → **Retry** (back to F9 for that Sub-Skill) |
| F11 | —                              | —                                                                                                                                                                                                                        | Macro certified when all its Sub-Skills are certified → Workflow validation → Workflow certified → version assigned → frozen → notification                                                                                                                                   | "Workflow 1.0.0 certified and frozen"                                                                 |
| F12 | FDE → Certification / Versions | Opens certification tree;**Export package**                                                                                                                                                                         | Builds zip (manifests, code, evidence, checksums)                                                                                                                                                                                                                                  | Download                                                                                              |
| F13 | FDE → SOW (later)              | Client changes scope:**Create new SOW version** → edit → approve                                                                                                                                                  | Impact analysis → only affected Sub-Skills invalidated → rebuild F9–F11 → version 2.0.0; unchanged parts reuse certification                                                                                                                                                   | Impact preview before approving                                                                       |
| F14 | FDE → Sub-Skill (after freeze) | Fixes a detail in a Sub-Skill (same SOW)                                                                                                                                                                                  | New patch version 1.0.1; only that Sub-Skill rebuilds                                                                                                                                                                                                                              | New frozen patch version                                                                              |

## 3.3 Flow diagram

```text
[Admin] Project + Masters ─────────────────────────────┐ (context)
                                                       ▼
[FDE] Open project → Upload → ClamAV → Parse/OCR → Cognee → OKF Bundle → LLM → SOW v1
                                                                               │
                         ┌───────── edit / regenerate (TipTap) ◄───────────────┤
                         ▼                                                     │
                     FDE approves ───────────────────────────────────────────►─┘
                         │
                         ▼
           ISATVON breakdown: Macro Skills → Sub-Skills (ISATVON JSON each)
                         │  FDE reviews/edits in grid → Generate
                         ▼
   ┌───────────── per Sub-Skill (parallel) ──────────────────────────────────────────┐
   │ Manifest → Dependency check → Jinja2 skeleton + LLM body → AST vs manifest       │
   │ → Ruff/Black/MyPy strict/ClamAV/Bandit → LLM test data + ≥3 Promptfoo cases     │
   │ → CubeSandbox → PASS → Sub-Skill CERTIFIED                                       │
   │        FAIL → correction #1 → #2 → NEEDS_FDE_REVIEW → FDE fix → Retry            │
   └──────────────────────────────────────────────────────────────────────────────────┘
                         ▼
   All Sub-Skills of a Macro certified → Macro CERTIFIED
   All Macros certified → Workflow validation → Workflow CERTIFIED → versioned → FROZEN → Export
```
